# 常见问题（FAQ）

快速解答下载与日常使用中的高频问题。安装与使用步骤见 [user-guide.md](user-guide.md)。

**Q：Windows 打开安装包提示 SmartScreen「未知发布者」？**
开源项目未做付费签名，属预期行为。「更多信息」→「仍要运行」即可；macOS 的 Gatekeeper 同理（右键「打开」或系统设置中放行）。

**Q：安装包为什么这么大？**
发布包内置完整的 DeepSeek Harness 运行时（Node + 依赖闭包），换来的是零环境、断网也能启动的确定性。不需要安装 Node.js，也不会污染系统 PATH。

**Q：首次启动出现深色「重连中」画面正常吗？**
正常。首启会在后台补装随包插件并自动重启运行时，全程两三秒，之后不会再频繁出现。

**Q：升级后我的会话还在吗？**
同一数据目录内的常规升级（v0.3+ 之间）在；会话内容持久化在本地数据目录，且应用保持稳定端口，重启后会自动回到上次的会话。

**Q：我的数据存在哪里？会上传吗？**
全部存在本机共享数据目录 `~/.dsh`（Windows `%USERPROFILE%\.dsh`，各平台路径见 [user-guide.md](user-guide.md)）。模型调用直接从你的机器发往你配置的服务商；应用本身不上传你的数据。

**Q：它和终端版 dsh / TUI 共享数据吗？**
共享。桌面端使用与 CLI/TUI/Web 相同的规范 home（`~/.dsh`，可用 `DSH_HOME` 覆盖），会话、凭据、工作区天然互通；桌面自己的插件装配放在专属的 `profiles/desktop` 子目录，不干扰其他前端。从 v0.2.x 及更早版本升级属于破坏性切换，旧私有目录不自动迁移——升级前备份，详见 [user-guide.md](user-guide.md)。

**Q：有系统托盘 / 最小化到托盘 / 开机自启吗？**
都有：托盘图标常驻（菜单含显示主窗 / 检查更新 / 退出），点击关闭按钮默认隐藏到托盘；开机自启在 设置 →「桌面设置」开启。详见 [user-guide.md](user-guide.md)。

**Q：更新失败或更新按钮报错怎么办？**
安装包经 SHA256 强校验，校验失败会拒绝安装——这是安全设计。直接从 Releases 重新下载最新安装包覆盖安装即可，用户数据不受影响。

**Q：自己给桌面端接了 MCP 服务器（stdio），但工具一直不出现？**
工具不出现即连接失败——当前版本对 MCP 连接失败没有任何提示。优先检查两点：stdio 的 `command` 必须写**绝对路径**（桌面图标启动的应用看不到终端里的 `~/.local/bin` 等用户目录）；命令在终端能跑不代表 GUI 会话可用。

**Q：Linux 安装时缺依赖？**
deb/rpm 已声明运行所需的 WebKitGTK 等依赖，用包管理器安装（`apt install ./xxx.deb`）会自动解决；避免绕过包管理器直接解压。

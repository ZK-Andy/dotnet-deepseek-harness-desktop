# Agent Note: ide0005-enforce-via-format-gate

Status: implemented

## Problem

`.editorconfig` 开启 `dotnet_diagnostic.IDE0005.severity = warning`（移除无谓 using）。但 IDE0005 在 MSBuild 面需 `GenerateDocumentationFile=true` 才触发。若直接开启该属性，会连锁产生大量 CS1591（公共可见成员缺 XML 文档），需决定如何协调 IDE0005 强制与 XML 文档契约。

## Decision

- **IDE0005 的唯一强制路径 = `dotnet format --verify-no-changes --severity warn` 门禁**（ci.yml 已运行），不依赖 `GenerateDocumentationFile`。
- **测试工程开 `GenerateDocumentationFile=true`**：其所有 `public` 测试类/方法均补全 XML 文档（CS1591 清零），同时让 IDE0005 在测试工程 build 面也强制。
- **主工程不强制 `GenerateDocumentationFile`**：Ryn.Callbacks 源生成器为 `[RynCallback]` 类产出 `public` DI 扩展（`RynNavigationCallbacksRynExtensions.AddRynNavigationCallbacks`）。该符号无法手写文档，且下述两个常规豁免手段都无效，故不开启（宁可少一步 build 面 IDE0005 强制，也不引入无法消除的 CS1591）。主工程 csproj `NoWarn` 补 `EnableGenerateDocumentationFile` 仅压制 MSBuild 侧该指导性提示。

## Alternatives considered

- **全局 `NoWarn` 压制 CS1591 后开启 `GenerateDocumentationFile`**：落败——会连带压制一切手写公共 API 的缺文档缺口（含测试方法），与「公共 API 带 XML doc 契约」冲突，属歧义取舍。
- **用 `.editorconfig` `[**/*.g.cs]` 关闭生成文件 CS1591**：落败——Roslyn 在源生成阶段之后才读 `.editorconfig`，路径 glob 匹配不到编译期**内存**生成文件（独立 probe 实测无效），对由 `EmitCompilerGeneratedFiles` 落盘的副本也不生效（其非 Compile item）。
- **依赖 `// <auto-generated />` 头抑制生成文件 CS1591**：落败——probe 实测该头并不抑制 CS1591（`GenClass` 照样报）。
- **主工程也补手写公共成员文档以开启**：部分采纳——主工程手写公共成员（`CliShimPlanner` 常量、`UpdatePlatform.Rpm`）已补文档；但因 2 个源生成 public 符号仍无法消除 CS1591，主工程仍不开启。

## Consequences

- IDE0005 双侧 build 面强制执行仅测试工程达成，主工程靠 `dotnet format` 门禁（单一且有效）。
- 主工程 2 个源生成 `public` 符号（`RynNavigationCallbacksRynExtensions` + `AddRynNavigationCallbacks`）当前不受 XML 文档契约强制；留待 Ryn.Callbacks 生成器输出带文档或改 `internal` 后，主工程再开启 `GenerateDocumentationFile`（届时移除本条处理）。
- 测试工程 ~700 个公共测试方法已补真实行为 `<summary>`，CS1591 清零。
- 验证：build 0 警告（测试工程 0 CS1591）、test 467/467、`dotnet format --verify-no-changes --severity warn` exit 0。

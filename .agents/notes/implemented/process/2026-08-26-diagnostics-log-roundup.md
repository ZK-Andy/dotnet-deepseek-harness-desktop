# Agent Note: 诊断日志全路径收口——实机偶发卡死暴露的三类盲区清零

Status: implemented

## Problem

v0.3.10 实机（Fedora Wayland）出现一次性偶发卡死：23:03 起实例对一切外来事件（托盘菜单、唤起、launcher 激活）无响应，重启后才恢复，且 restart 后复现试验阴性（最大化→隐藏→唤回循环无卡死）。排查时 host.log 出现三类盲区，导致无法判定根因：

1. **stdout-only 盲区**：一批 `Console.WriteLine` 诊断（自更新状态回调失败、安装授权通过、Ryn Run 生命周期等）在桌面形态下 stdout 不可见（v0.2.1 早证），host.log 完全无痕——恰是本次最需要的安装链与回调异常面。
2. **事件到达性盲区**：托盘事件链路除了「显示主窗成功」外无日志——「事件没到 / 到了被忽略 / 受理后卡死」三者无法区分。
3. **生命周期细节盲区**：隐藏（hide-to-tray）动作与隐藏前采样值、唤回两拍的执行、launcher UDS 请求到达、更新检查的网络起点/耗时均静默。

用户拍板原则：**未到稳定版，日志是唯一抓取手段**——诊断面按「全路径留痕、可区分到环节」补齐，不做盲修。

## Decision

日志面按四组收口（本轮无行为变更，仅观测面；测试 305→308）：

1. **stdout-only 全收口 HostLog**：18 处 `Console.WriteLine` 迁入 `HostLog.Write`（stdout 与 host.log 双写，CLI 形态可见性不丢）——含 UpdateStateMachine 状态回调失败 ×2、安装授权通过/关窗失败/start 失败、Ryn Run 开始/异常/结束、启动关键行（runtime/dsh web/降级 stderr 尾巴）、端口读写失败、run-marker 清理失败、诊断导出、Ryn opts 等。
2. **托盘事件全路径留痕**（`DesktopTrayCommandRouter`）：入口打事件名+载荷（>120 字符截断）；忽略分支打原因；检查更新打「已受理」+「完成：状态/通知文案/中间态不通知」+「栈未装载无动作」。
3. **窗口与唤回生命周期留痕**：隐藏打「窗口隐藏到托盘（隐藏前最大化采样=N）」「窗口已隐藏」（隐藏成功=主线程活性的铁证）；唤回兜底拍打「显示后兜底确认已发」。
4. **更新链与 launcher 留痕**：`ReleaseMetaClient` 检查起点/终点（repo/rid/feed 超时/最新稳定版/耗时）；`InstallerDownloader` 下载开始/完成（字节数、耗时）/失败/校验通过；`UpdateInstaller` pkexec 派生与授权观察结果；`PrimaryListener` 收到请求/忽略/处理完成。以上经可选 `Action<string>? log` 构造参数注入（宿主接 `HostLog.Write`，测试可注入收集器断言）。

回归面：新增 3 个托盘路由日志契约断言（到达必留痕、忽略双痕、检查受理+装载状态）。

## Alternatives considered

- **盲改 `TrayRecallMaximize` 两拍**（首唤后跳过预置等）：在「复现阴性=根因未实锤」下破坏已实证的首唤无闪变，落败——行为修复必须有复现证据，本轮只补齐观测。
- **加主循环心跳/健康轮询日志**：每 10s 探针已有（PageHealthMonitor），高频心跳只会刷爆 host.log 且不定位到环节，落败——留痕粒度到事件环节而非时间点。
- **等待下次复现再补日志**：下次若复现仍无痕则白等，且诊断 zip 外发同样缺痕，落败——观测先行。
- **拆分到多个小提交**：日志面同属一次收口（互不独立可提交），单提交便于回退与评审，采纳。

## Consequences

- 下次同类卡死，host.log 按时间线可直接判定：托盘事件到没到（到达行）→ 被忽略还是受理 → 动作执行到哪一拍（预置/显示/兜底）→ 隐藏/launcher 是否活着（隐藏成功行/UDS 请求行）→ 主循环是否退出（Ryn Run 结束行）。
- 日志体积增长有限：新增行均为事件级（每次交互一条），无轮询噪音；载荷截断防长串。
- 所有新增日志经 `HostLog` 出口，SecretMasker 脱敏面自动覆盖，诊断 zip 外发安全不变。

## Testing

- `dotnet test` 308/308（新增托盘路由日志契约断言 3 例，既有 305 全绿）；build 0 警告；门禁三脚本绿。
- 实机验证转交：下次发版后正常操作一轮（托盘各菜单项、隐藏唤起循环、检查更新、launcher 二启），host.log 应出现上述各环节行；若卡死复现，日志应能定位到拍级。

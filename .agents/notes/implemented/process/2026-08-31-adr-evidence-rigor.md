# Agent Note: adr-evidence-rigor（ADR 证据严肃性——现象/机制分离 + 数值声明标强度 + 勘误/撤回通道一次补齐）

Status: implemented

中文（双语暂不启用；启用时恢复 .md + .zh.md 配对 + .i18n.yaml）

## Problem

ADR 骨架（`Problem`/`Decision`/`Alternatives considered`/`Consequences`）由 `verify-adr-format.py` 机器强制，但强制的是**结构与禁用词**，不是**证据的严肃性**。当前"留评审/语义"层面（对照根 AGENTS.md 评审检查项里 D001–D003、R1/R3/IPC 那批机器无法强制的兜底项）存在一类未被机检查、也无流程兜底的缺口：

1. **现象与推断成因混写**。`Problem`/`Decision` 里既不区分"可复现的观测"，也不区分"我推断的机制"。推断一旦写成判断句，后续 ADR 会默认把它当已验证前提引用，层层堆叠后错误被放大。
2. **测量数字无强度标注**。`Problem`/`Decision`/`Consequences` 里的百分比、提升值、样本数没有统一的"这是探索性还是已证"标记；小样本（n=2/n=3）的观测被当成定论传播，后续决策基于它做取舍。
3. **implemented 后理论被证伪，无正式撤回通道**。`rejected/` 只管"未采纳"，`archived/` 冻结后"禁改/禁删"——但"我当时选对了路径、依据的理论后来错了"这种事，既不能改 archived，也没有地方钉勘误，只能靠事后口述或散落在会话里。

此三类并非纯理论：调研 dsh-routing-suite 系列（yjh051108 三仓库，2026-08）时，作者病根正是"把观测现象当本质""n=2 称 P23 实测""只能靠后来的道歉函认错"。这些是**可引以为鉴的反面样本**，说明缺了证据严肃性，ADR 体系会把人推向"先有结论、再补证据"。

## Decision

为 ADR 体系增加**证据严肃性三件套**，落地为写作/评审约定，不新增机器门禁（避免过度机械化，保留语义判断；与"留评审 + 三重审核"的既有兜底齐平）。

### 1. 现象/机制分离（治"现象当本质"）

- `Problem`/`Decision` 中，凡**推断成因**必须标注【推断 · 未证】；单纯的**可复现观测**保持现状即可。
- 未证成因**不得**作为后续 ADR 或实现的默认前提；后续引用时需重新显式写明"它以可复现现象为据，机制未证"。
- 判据：能复现（有对照、有稳定结果）→ 观测；无法复现、属于解释层 → 推断成因。

### 2. 数值声明标强度（治"小样本当定论"）

- ADR 中的测量数字必须带 **n + 实验设置**（模型、条件、对照基线）。
- **n<3 一律标【探索性】**；只有达到可统计意义的样本才可标【已证】。
- 宣传性措辞（"提升很大""接近完美"）不得单独作为决策依据，除非同一段给了 n 与设置。

### 3. 勘误/撤回通道（治"理论证伪无归档路径"）

- implemented 后发现依据理论被证伪、但工程决定仍要保留时：在 Status 下插一行
  `Erratum: YYYY-MM-DD — <撤回什么 / 保留什么>`，然后按 `archived/` 冻结规则处理。
- **不删除、不重写**已归档正文；勘误行是唯一新增物，永久保留可追溯。
- 与 `rejected/`（未采纳）区别：这里处理的是"已采纳后发现依据错"，主体不动、只钉勘误。

## Alternatives considered

- **只做三条里的第 1 或第 2 条（现象/分离 & 标强度）**：省事，但推理链断层、数值无强度的问题确实存在，只修一半会让"勘误"落回无通道状态。落败；三件套一起上。
- **把三件套做成机器门禁（verify-adr-format.py 报错强制）**：证据严肃性是语义判断，"标【推断·未证】""n<3" 难以用词法可靠判定，强行机械化会催生"凑格式"而非"真标注"，且违背"机器只兜结构、语义靠评审"的既有分工。落败；写作/评审约定。
- **新增独立 `retracted/` 状态目录**：与"状态即目录"生命周期分离，会扩大状态机并让 `archived/`（永久冻结）语义复杂化。落败；沿用 `archived/` + Erratum 行，状态机不扩张。

## Consequences

**代价**：新增写作约定会提高 ADR 撰写门槛，但只约束"涉及推断/数字"的段落，纯实现/布局 ADR 不受影响（缓解接受度问题）。

**收益**：ADR 里的推断与观测不再混淆，测量数字有强度刻度，真被证伪的理论有正规撤回出口——这三类"机器无法强制"的语义缺口有了写作/评审兜底。

**已知取舍**：
- 不新增机器门禁，故"标注可能流于形式"（作者只为过审而贴【推断·未证】标签）无法被机器拦截。缓解：作为评审/三重审核的核对项。
- `Erratum` 行格式无机器校验（与 `Archived:` 行不同），可能格式不统一。缓解：用惯例 + 评审兜底，未来确有需要再扩展 `verify-adr-format.py`。

**Testing**：写作约定属方法论，不引入独立测试；通过本 ADR 自身（推断处标【推断·未证】、无 n=2 当定论）作为落地示例，并由 `verify-adr-format.py` 校验其仍报 OK（证明与机器校验不冲突）。
